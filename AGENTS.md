# Project instructions

- Do not create, modify, build, install or release Warhall client patches. Implement game changes through supported WDS data, native game features and asset definitions.
- Keep reserve models in native WDS ExtraItems definitions.
- Commit and push authorized work directly to main.
- Use a single Starcraft/ dataset. main feeds Warhall Test; release feeds production. Promote tested main commits to release without copying dataset folders or rewriting published history.
