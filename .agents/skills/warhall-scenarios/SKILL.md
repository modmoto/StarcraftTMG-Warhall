# Scenarios

Read the official scoring card and verify the title, scoring conditions, timing and both faces. Use warhall-card-artwork for extraction. Preserve existing card IDs and map the card into the Missions group. Verify New Recruit mission names resolve to the card and remain selectable candidates.

Keep the scoring choice separate from deployment geometry. The selected deployment owns marker and border placement. Check the card popup and artwork in Test and confirm the scenario does not spawn a second set of markers.
